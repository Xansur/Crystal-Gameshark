# Pokémon Crystal GameShark

A GameShark-style cheat menu mod for **Pokémon Crystal** running on
[Gen1Recomp](https://github.com/bryanthaboi/gen1recomp).

The mod adds an in-game **CODES** menu that provides convenient access to
cheat-style functions

## Features

### CODES

- Heal Party (updated to heal HP, PP and Status)
- Wild Pokémon Modifier
- Walk Through Walls
- EXP Multiplier
- Money
- All Badges
- Shiny Pokémon
- Master Ball ×99
- Rare Candy ×99
- Pokéballs
- Items
- TMs / HMs
- Key Items
- Gender Modifier

## Wild Pokémon Modifier

The Wild Pokémon Modifier contains a list of all **251 Pokémon** in
National Pokédex order.

Selecting a Pokémon sets it as the species for the **next wild encounter**.
